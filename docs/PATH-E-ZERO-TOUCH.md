# 🅴️ Путь E: «Партнёр просто получает заявки» (Zero-Touch)

> Партнёр не покупает VPS, не регистрируется на Profi, не настраивает бота.
> Всё делают Админ и Менеджер. Партнёр только получает заявки в Telegram.

| # | Админ (ты) | Менеджер | Партнёр |
|---|------------|----------|---------|
| 1 | Покупает VPS под партнёра | Находит партнёра | **Ничего** |
| 2 | Регистрирует Profi аккаунт | Узнаёт нишу, бюджет | **Ничего** |

## 🔄 Пошагово

### Шаг 1: Менеджер → разговор с партнёром

**Скрипт разговора:**

> «Мы берём на себя всё. Вы просто говорите какие заказы ищете,
> и начинаете получать их в Telegram. Ничего настраивать не надо.
> 999 ₽/мес. Первая неделя — бесплатно.»

**Что нужно узнать у партнёра:**

```
☐ В какой нише работает? (сайты, дизайн, seo, контекстная реклама...)
☐ Какой бюджет заказов? (от 5 000? от 30 000?)
☐ Какие заказы НЕ интересуют? (игры, 1с, бухгалтерия...)
☐ Города? (Москва, СПб, вся Россия?)
☐ Telegram: переслать любое сообщение боту @getmyid_bot
   → он покажет Chat ID. Партнёр присылает это число менеджеру.
```

**Всё! Больше от партнёра ничего не нужно.**

---

### Шаг 2: Админ → подготовка инфраструктуры

```
1. Купить VPS в Казахстане (ps.kz, 4 GB RAM, ~2500 ₽/мес)
   └── Это расходи админа или заложены в подписку партнёра

2. Зарегистрировать новый аккаунт на Profi.ru как «специалист»
   ├── Email: партнёра или свой (можно сделать на свой)
   ├── Имя: как партнёра
   └── Категории: выбрать под нишу партнёра

3. Создать Telegram-бота через @BotFather
   ├── /newbot → имя: «Leads [Ниша]»
   ├── Получить Bot Token
   └── Партнёр нажимает /start в этом боте

4. Создать source в админке
   ├── Логин/пароль Profi
   ├── Ключевые слова под партнёра
   ├── Минус-слова
   ├── Бюджет от/до
   ├── Telegram Chat ID + Bot Token
   └── Сохранить → записать Source ID

5. Запустить агента на VPS
   ssh root@VPS_IP
   curl -fsSL https://leads.konversus.ru/agent/setup.sh | bash -s "SOURCE_ID"
```

---

### Шаг 3: Тест

```
Менеджер → партнёру:
  «Всё готово! В ближайшие 10-15 минут должны пойти первые заявки.
   Как получите — напишите, всё ли устраивает.»

Админ → проверяет:
  pm2 logs leads-agent — нет ошибок входа?
  Heartbeat приходит?

Партнёр → получает заявку → пишет «ок, работает»
```

---

### Шаг 4: Оплата

```
После тестовой недели:
  Менеджер → «Продолжаем? 999 ₽/мес».
  Партнёр → оплачивает.
  Админ → активирует подписку.

Если партнёр отказывается:
  Админ → удаляет source, останавливает агента, удаляет VPS.
```

---

## ⚠️ Риски и важные моменты

| Риск | Как решаем |
|------|------------|
| **Profi блокирует за одинаковый IP** | Каждый партнёр = отдельный VPS = свой IP. Админ покупает VPS под каждого. |
| **Партнёр хочет доступ в кабинет** | Даём логин/пароль от leads.konversus.ru/dashboard — он видит статистику. |
| **Партнёр хочет сменить ключевые слова** | Пишет менеджеру → админ меняет в админке → агент сам подхватит при следующем цикле. |
| **Партнёр не платит** | Стоп агента → удаление source. Автоматизации пока нет, руками. |
| **Аккаунт Profi заблокировали** | Алерт админу. Создать новый аккаунт, обновить source. |
