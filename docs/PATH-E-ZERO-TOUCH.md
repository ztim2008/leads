# Путь E: партнёр получает заявки (операторское подключение)

> **Версия:** 2.0 · 21 августа 2026  
> Партнёр **не** настраивает сервер и **не** разбирается в агенте.  
> Подключение делает **админ**. Продажи / Zoom — **напарник**.  
> Партнёр: решение, оплата, Telegram, отклики, фильтры в кабинете.

Устаревшее в v1 (снято): «999 ₽/мес», «неделя бесплатно», обязательный BotFather у каждого партнёра, партнёр сам покупает VPS как условие старта.

Актуальная логистика: [LOGISTICS.md](./LOGISTICS.md) · CJM: [CJM_PARTNER_SALES.md](./CJM_PARTNER_SALES.md)

---

## Что получает партнёр

```
Telegram — карточка заказа с Profi
  · название, бюджет, город, ссылка
  · открыл → откликнулся сам

Кабинет https://leads.konversus.ru
  · заявки
  · фильтры (заголовок ± / текст ±, бюджет, часы…)
  · счёт: оплачен / не оплачен

Не получает:
  · доступ к SSH / «ускорить ленту»
  · право включать сбор (стоп/старт — админ)
```

## Кто что делает

| Шаг | Напарник | Админ | Партнёр |
|-----|----------|-------|---------|
| 1 | Находит, Zoom, объясняет | — | Слушает, решает |
| 2 | Собирает нишу / TG / договорённость по оплате | — | Платит по договорённости |
| 3 | Передаёт чек-лист | VPS + партт в системе + agent v2 | При необходимости отдаёт доступ к Profi админу |
| 4 | «Смотрите TG» | Пульт: HB, CB, заявки | Читает карточки, откликается |
| 5 | Лёгкий check-in | Счёт, поддержка, пауза | Крутит фильтры в кабинете |

**Zero-touch по технике** = партнёр не ставит Node/Playwright/PM2.  
**Не zero-touch по смыслу** = нужны ниша, Telegram, оплата и (обычно) доступ к кабинету специалиста Profi.

## Пошагово

### 1. Напарник → Zoom

Скрипт: [SALES_ZOOM_SCRIPT.md](./SALES_ZOOM_SCRIPT.md).  
SMS: [SALES_SMS_PITCHES.md](./SALES_SMS_PITCHES.md).

Узнать:

```
☐ Ниша
☐ Плюс / минус темы
☐ Бюджет от–до (если есть)
☐ Город / регион
☐ Telegram для заявок
☐ Есть ли уже кабинет специалиста на Profi
☐ Договорённость по оплате и дате старта
```

### 2. Админ → инфраструктура

```
1. Купить/выделить VPS под партнёра (свой IP)
2. Создать партнёра: админка или npm run operator:onboard
3. Profi: логин партнёра (предпочтительно) или согласованный новый кабинет специалиста
4. Telegram: chat партнёра (единый бот сервиса — этап 4.9; пока — рабочая схема из онбординга)
5. Install agent v2 на VPS (команда из карточки / CLI)
6. Проверить HB < 15 мин, CB CLOSED
7. Выставить/отметить счёт
```

Характеристики VPS (ориентир): 2 GB+ RAM, Ubuntu 22/24, исходящий HTTPS. Домен не обязателен.

### 3. Проверка с партнёром

```
Напарник → «Подключено. Ждите карточку в Telegram.»
Админ   → Пульт / verify
Партнёр → «Вижу заявку» = путь E закрыт успешно
```

### 4. Если не платит / отказался

```
Админ → пауза или стоп сбора в системе (без опасных рестартов входа)
      → по ситуации: отключить source / не продлевать VPS
Напарник → не угрожает «заблокируем аккаунт Profi»
```

## Риски

| Риск | Как |
|------|-----|
| Общий IP на несколько Profi | Запрещено: 1 VPS = 1 аккаунт |
| Партнёр просит «ускорить» ленту | Отказ; правим фильтры |
| login_failed / CB OPEN | Стоп, разбор; не сброс CB вслепую |
| Пароль в чате рекламы | Только админу, отдельный канал |
| Playwright на хабе | Запрещено (`profiOnHub: false`) |

## Что партнёр может менять сам (после старта)

| Можно в кабинете | Нельзя |
|------------------|--------|
| Фильтры заголовка/текста, бюджет, часы (в рамках политики) | Логин/пароль Profi, интервал ленты, antiDetect |
| Смотреть счёт | Включать/выключать сбор (только админ) |

Смена фильтров подхватывается на следующем config pull — **без** рестарта VPS-агента.
