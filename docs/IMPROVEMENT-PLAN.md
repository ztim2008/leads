## Фаза 1: Конверсия (ближайшие дни)

### 1.1 Авто-отклик на Profi
Самое сильное. Система не просто находит заказ — она сама откликается.

```
Нашла заказ → AI написал отклик → [Отправить на Profi.ru]
```

Технически: Playwright уже авторизован. Добавить `page.click('[data-testid="respond_btn"]')` → заполнить текст → отправить.

**Эффект**: ты первый откликаешься на каждый подходящий заказ. Конкуренты не успевают.

### 1.2 Шаблоны откликов с переменными
Сейчас 4 типа откликов генерируются AI. Сделать возможность сохранять свои шаблоны с подстановкой: `{ИМЯ}`, `{БЮДЖЕТ}`, `{ПОРТФОЛИО}`.

### 1.3 Умный фильтр «Только горячие»
Показывать только заявки с рейтингом ≥70 И бюджетом ≥50К И от живого человека. Быстрый пресет-фильтр.

## Фаза 2: Источники (неделя)

### 2.1 Kwork коннектор
Публичное API, простая интеграция. Заказы категорий: разработка, дизайн, SEO.

### 2.2 FL.ru коннектор
RSS-лента заказов. Парсинг XML, нормализация.

### 2.3 Мульти-источник в одном экране
Заявки со всех площадок в единой ленте с цветовой маркировкой источника.

## Фаза 3: Аналитика (неделя)

### 3.1 Дашборд статистики
- Заявок в день (график)
- Конверсия: найдено → отклик → сделка
- Средний чек
- Лучшее время для публикации заказов

### 3.2 Отчёт для клиента
PDF-отчёт за неделю: «Система нашла 45 заявок, вы откликнулись на 12, сделок — 3».

## Фаза 4: Командная работа (2 недели)

### 4.1 Роли в workspace
Владелец → Менеджер → Исполнитель. Разные права доступа.

### 4.2 Назначение заявок
Владелец видит все заявки → назначает конкретному менеджеру → менеджер видит только свои.

### 4.3 Общий Telegram-бот
Один бот на workspace. Уведомления с указанием кому назначена заявка.
