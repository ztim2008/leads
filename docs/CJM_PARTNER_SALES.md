# CJM — путь клиента от первого контакта до подключения админом

> Для: **напарник** (поиск людей с Profi, реклама, Zoom) и **админ** (подключение в системе)  
> Продукт: Konversus Leads · https://leads.konversus.ru  
> Обновлено: 21.08.2026  
> Сценарий разговора на Zoom: [SALES_ZOOM_SCRIPT.md](./SALES_ZOOM_SCRIPT.md)

---

## Роли (кто за что отвечает)

| Роль | Кто | Зона |
|------|-----|------|
| **Напарник** | Ищет людей, реклама, Zoom, доверие | Коммуникация, квалификация, сбор «мягких» данных, эскалация админу |
| **Админ** | Алексей | VPS, Profi в системе, агент, счёт, Пульт, техника |
| **Партнёр** | Клиент | Решение, оплата, Telegram, отклики на Profi, фильтры в кабинете |

**Правило:** напарник **не** ставит агента на VPS и **не** правит production. Админ **не** ведёт холодную воронку — получает готовый пакет после «да».

---

## Карта пути (одним взглядом)

```
Реклама / поиск на Profi
        │
        ▼
Первый контакт (TG / звонок)     ← напарник
        │
        ▼
Квалификация (свой / не свой)    ← напарник
        │
        ▼
Zoom 20–30 мин                   ← напарник (+ админ по желанию)
        │
        ▼
«Да» → оплата / договорённость   ← партнёр + напарник фиксирует
        │
        ▼
Чек-лист данных → админу         ← напарник
        │
        ▼
Подключение в системе            ← только админ
        │
        ▼
Первая заявка в Telegram         ← проверка вместе
        │
        ▼
Работа: фильтры, счёт, поддержка ← партнёр + админ
```

## Этапы CJM

### 0. Охват (до разговора)

| | |
|--|--|
| **Кто** | Напарник |
| **Где** | Реклама, личные сообщения специалистам Profi, рекомендации |
| **Сообщение** | Не «робот/парсер», а: заявки с Profi в Telegram без сидения в ленте |
| **Цель** | Согласие на короткий Zoom или созвон |
| **Не делать** | Сразу просить пароль Profi; спорить в комментариях |

**Критерий выхода:** слот Zoom или «напишите в TG».

### 1. Первый контакт

| | |
|--|--|
| **Кто** | Напарник |
| **Задачи** | Представиться, 1–2 вопроса про боль, предложить Zoom |
| **Партнёр чувствует** | «Это не спам-рассылка, меня услышали» |
| **Артефакт** | Имя, ниша, Telegram, «уже на Profi?» |

**Мини-квалификация (да/нет):**

- Специалист (или готов завести кабинет специалиста), не чистый заказчик  
- Есть ниша с заказами на Profi (сайты, ремонт, красота…)  
- Готов получать заказы в Telegram и сам откликаться  
- Понимает, что это сервис подключения, не «бесплатный бот»

**Стоп-факторы:** «хочу чтобы бот сам писал клиентам и закрывал сделки»; «дайте доступ ко всем заказам Profi без кабинета»; отказ от отдельного безопасного контура.

**Критерий выхода:** Zoom назначен **или** отказ зафиксирован.

### 3. Согласие и деньги

| | |
|--|--|
| **Кто** | Напарник фиксирует; **оплату и флажок в системе** отмечает админ |
| **Партнёр** | Платит по реквизитам / способу, который дал админ |
| **В системе** | Оператор → Счета: подключение разово, период (поддержка + API ИИ + VPS), флажок **оплачен / не оплачен** один у админа и партнёра |

Ориентир цен (админ может менять в админке):

| Статья | |
|--------|--|
| Подключение | 5 000 ₽ разово |
| Поддержка | 2 000 ₽ / мес (с 1-го месяца) |
| API ИИ | 1 700 ₽ / мес |
| VPS | 40 ₽ / день |

**Критерий выхода:** ясно, платит ли до подключения или после первой заявки (решает админ); напарник не меняет условия сам.

### 4. Сбор данных (логистика для напарника)

Напарник заполняет и **одним сообщением** шлёт админу.

#### Шаблон передачи админу

```text
ПОДКЛЮЧЕНИЕ — после Zoom

Имя / как обращаться:
Telegram:
Ниша:
Город / регион:
Уже есть Profi специалист? да/нет
  логин Profi: (если да — передать админу отдельно, не в общий чат)
Плюс-темы (что брать):
Минус-темы (что не брать):
Бюджет от–до (если есть):
Куда слать заявки (Telegram chat / username):
Договорённость по оплате: (предоплата / после старта / сумма)
Когда удобно подключить: (сегодня / дата)
Заметки с Zoom:
```

| Собирает напарник | Делает только админ |
|------------------|---------------------|
| Ниша, фильтры словами | VPS, SSH, install агента |
| Контакт TG | Создание партнёра в админке / CLI |
| Факт «есть Profi» | Хранение пароля Profi, запуск сбора |
| Договорённость по деньгам | Флажок «оплачен», период, пауза |

**Пароли:** root VPS и пароль Profi — партнёр отдаёт **админу** (лично / отдельный защищённый канал), не в рекламный чат и не в Zoom-чат на запись.

**Критерий выхода:** админ написал «пакет полный, беру в работу» или «не хватает: …».

---

### 5. Подключение в системе (админ)

Партнёр и напарник в это время **ждут статус**, не крутят сервер.

1. Создать партнёра (админка / `operator:onboard`): email + пароль кабинета, Profi, лимит, TG.  
2. Поднять/привязать VPS, поставить agent v2 (`install.sh`).  
3. Проверить: heartbeat &lt; 15 мин, CB CLOSED, статус на Пульте ок.  
4. Выдать карточку доступа (кабинет + что настроено).  
5. В Счетах выставить период / отметить оплату по факту.

**Критерий выхода:** админ → напарнику и партнёру: «подключено, ждите первую карточку в TG».

---

### 6. Первая ценность (aha-момент)

| | |
|--|--|
| **Кто** | Партнёр получает заявку; напарник спрашивает «дошло?» |
| **Админ** | Если тишина в рабочие часы при online — смотрит фильтры/рынок, **не** рестартит вход без причины |
| **Успех** | Хотя бы одна релевантная карточка в Telegram |

**Критерий выхода:** партнёр подтвердил «вижу заявки» → сделка считается доведённой до продукта.

---

### 7. Дальше (после подключения)

| Партнёр | Напарник | Админ |
|---------|---------|--------|
| Читает TG, откликается | Лёгкий check-in 1 раз в первые дни | Мониторинг, счёт, пауза/продление |
| Крутит фильтры в кабинете | Не обещает смену интервала ленты | Не трогает agent без нужды |
| Смотрит Счёт (оплачен/нет) | Новых людей в воронку | Техподдержка, флажок оплаты |

## Таблица «момент истины»

| Этап | Партнёр думает | Риск | Что говорим / делаем |
|------|----------------|------|----------------------|
| Реклама | «Очередной спам» | Игнор | Коротко про Telegram + свою нишу |
| Zoom | «Забанят аккаунт» | Отказ | Свой сервер / свой контур, без общих IP |
| Сбор данных | «Отдам пароль — страшно» | Отвал | Только админу, зачем нужен доступ |
| Ожидание установки | «Тишина = кинули» | Тревога | Статус от напарника: «админ подключает, ETA» |
| Первые заявки | «Мало / много мусора» | Разочарование | Фильтры в кабинете, без ускорения ленты |
| Счёт | «Непонятно за что» | Конфликт | Одна полоска оплачен/не оплачен + расшифровка |

## SLA между напарником и админом

| Событие | Кто | Срок (ориентир) |
|---------|-----|------------------|
| Zoom прошёл с «да» | Напарник → пакет админу | В тот же день |
| Пакет полный + оплата по договорённости | Админ → подключено | Обычно в тот же / следующий рабочий день |
| Подключено | Напарник → партнёру «смотрите TG» | Сразу |
| Нет HB / CB OPEN | Админ | Сразу человеку; напарник не «чинит» сам |

---

## Чего напарник не обещает

- Гарантию числа заявок в день  
- Что AI сам закроет клиента  
- Рестарт / «ускорим проверку ленты»  
- Self-service регистрацию на сайте  
- Работу без оплаты периода (если админ так не согласовал)
