# 📋 ТЗ: Leads AI v2 — автономная система сбора заявок

> **Версия:** 2.0 · **Дата:** 30.07.2026

> **Основание:** инцидент 30.07.2026 (блокировка Profi), 3 месяца эксплуатации v1

## 1. Цель системы

Автономная self-healing система сбора заявок с Profi.ru и Kwork.ru. Каждый партнёр работает через собственный VPS-агент. Центральный сервер — администрирование, мониторинг, приём заявок. **Нулевая вероятность блокировки аккаунтов Profi.**

---

## 2. Глоссарий

| Термин | Значение |
|--------|----------|
| **Агент** | Node.js процесс на VPS партнёра: Playwright + Profi/Kwork парсер |
| **Хаб** | Центральный сервер: Next.js + PostgreSQL + Redis |
| **Circuit Breaker** | Автомат защиты: после N ошибок — блокировка попыток на T минут |
| **Persistent Profile** | Браузерный профиль (куки, localStorage), сохранённый на диск между запусками |
| **Heartbeat** | Пульс агента: каждые 5 мин шлёт статус на Хаб |
| **Graceful Degradation** | Если Profi недоступен — продолжаем работать с Kwork |

## 4. Агент (VPS партнёра)

### 4.1 Жизненный цикл

```
[INSTALL] → [INIT] → [RUNNING] → [ERROR] → [COOLDOWN] → [RUNNING]
                ↑                      ↓                      ↓
                └──[FATAL]─────────────┘──────────────────────┘
```

### 4.2 Состояния агента

| Состояние | Описание | Действие |
|-----------|----------|----------|
| `installing` | Первый запуск, установка Playwright | Ждать |
| `init` | Загрузка конфига с Хаба | → running |
| `running` | Нормальная работа | Сбор заявок |
| `degraded` | Profi недоступен, работаем с Kwork | Продолжать |
| `cooldown` | Circuit breaker открыт | Ждать N минут |
| `blocked` | Аккаунт заблокирован (ручная разблокировка) | Алерт, стоп |
| `fatal` | Критическая ошибка (нет интернета, кончился диск) | Алерт, стоп |

### 4.3 Circuit Breaker (встроен в агента)

```
Правила:
  • 3 ошибки за 10 минут → OPEN (стоп на 60 мин)
  • После 60 мин → HALF-OPEN (пробный вход)
  • Пробный вход успешен → CLOSED (работаем)
  • Пробный вход неудачен → OPEN ещё на 120 мин
  • 5 циклов OPEN → BLOCKED (ручная разблокировка)

Хранение: JSON-файл на диске + heartbeat на Хаб
```

### 4.4 Persistent Profile

```
~/.leads-agent/profiles/{sourceId}/
├── cookies.json          # Куки сессии
├── localStorage.json     # localStorage Profi
├── state.json            # Состояние CB + статистика
└── chromium/             # Браузерный профиль Playwright
```

При старте агент загружает профиль с диска. Если профиль валиден (куки не истекли) — использует его без нового входа. Это сокращает число входов в Profi в 10 раз.

### 4.5 Человеческое поведение

```
Тайминги:
  • Проверка заявок: каждые 3-7 мин (случайно)
  • Скролл страницы: 2-4 случайных скролла по 200-500px
  • Паузы между скроллами: 1-3 сек
  • Клик по заказу: 15% вероятность раз в 3 цикла
  • Время на странице заказа: 3-8 сек
  • Мышь: случайные движения (Playwright mouse.move)
  • User-Agent: ротация между Chrome/Edge/Safari (macOS + Windows)
  • Viewport: случайный в пределах 1200-1600 x 800-1000
  • Язык: ru-RU
  • Часовой пояс: Europe/Moscow

Рабочие часы:
  • 08:00-22:00 МСК — активный сбор
  • 22:00-08:00 МСК — сон (1 проверка в час)
  • Суббота/воскресенье — активный сбор (заказы есть)
```

### 4.6 Установка (одна команда)

```bash
curl -fsSL https://leads.konversus.ru/agent/v2/install.sh | bash -s "SOURCE_ID"
```

Что происходит:
1. Установка Node.js 22 LTS
2. Установка Playwright + Chromium
3. Создание директории ~/.leads-agent
4. Загрузка агента с Хаба
5. Первый запуск → получение конфига → активация
6. PM2: автозапуск при ребуте, max 3 рестарта

### 6.1 Процесс (роль: Менеджер + Админ)

```
День 1:
  1. Менеджер находит партнёра
  2. Узнаёт: нишу, бюджет, Telegram
  3. Передаёт админу

День 1-2:
  4. Админ создаёт source в админке (2 мин)
     → Получает Source ID + команду установки

  6. Агент самоустанавливается (5 мин)

День 2-3:
  7. Партнёр получает первые заявки в Telegram
```

## 7. Мониторинг и алерты

### 7.1 Три уровня

```
Уровень 1: Health Monitor (cron каждые 5 мин)
  • PM2 процессы живы?
  • Docker контейнеры живы?
  • Диск/память в норме?
  • Telegram API доступен?
  → Алерт в Telegram при проблеме

Уровень 2: Agent Heartbeat (каждые 5 мин)
  • Агент онлайн?
  • Circuit breaker состояние?
  • Сколько заявок/ошибок?
  → Алерт если агент не на связи >15 мин

Уровень 3: Telegram Policeman (каждые 2 часа)
  • Самопроверка: отправить тестовое сообщение
  • Счётчик ошибок отправки
  → Алерт при 3+ ошибках подряд
```

### 7.2 Метрики

| Метрика | Порог | Алерт |
|---------|-------|-------|
| Агент офлайн | >15 мин | 🔴 Агент не на связи |
| Circuit Breaker OPEN | 1 раз | 🟡 Авто-кулдаун |
| Circuit Breaker → BLOCKED | 5 циклов | 🔴 Аккаунт заблокирован |
| Нет заявок | >60 мин | 🟡 Нет заявок |
| Диск | >90% | 🔴 Диск заполнен |
| Память | <200 MB | 🔴 Мало памяти |
| Telegram API | 3 ошибки подряд | 🔴 Бот не отвечает |

## 8. Безопасность

### 8.1 Защита от блокировки Profi

| Уровень | Мера |
|---------|------|
| IP | Один VPS = один аккаунт Profi |
| Браузер | Persistent профиль, не пересоздавать |
| Поведение | Случайные задержки, скролл, клики |
| Вход | Не чаще 1 раза в 4 часа (persistent сессия) |
| Ошибки | Circuit Breaker: 3 ошибки → стоп 60 мин |
| Ночь | 1 проверка в час вместо 10 |

### 8.2 Защита данных

| Данные | Хранение |
|--------|----------|
| Пароли Profi | PostgreSQL, поле зашифровано (AES-256) |
| Telegram токены | PostgreSQL |
| Куки браузера | Только на VPS партнёра (диск) |
| Логи | Ротация, 7 дней |
