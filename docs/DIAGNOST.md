# Техосмотр сайта — /diagnost

Сервис «Аудит сайта перед запуском рекламы»: https://leads.konversus.ru/diagnost. Вход — адрес сайта, выход — балл 0–100, готовность к рекламе в %, причины каждого балла, приоритеты и два PDF.

**Доступ:** запускать аудит может только админ (сессия leads, `role = admin`, проверка `requireAdminUser` в `POST /api/diagnost`, суточный лимит для админа не действует). Остальным — 403 и сообщение «Администратор закрыл доступ. Для открытия обратитесь t.me/bilarius» (`src/lib/diagnost/access.ts`). Отчёты `/diagnost/r/<slug>` и PDF открыты всем по ссылке.

## Как работает

1. `POST /api/diagnost` создаёт запись `diagnost_audits` (status `queued`), ставит куку владельца `dg_owner` (год, httpOnly). Лимит: `DIAGNOST_DAILY_LIMIT` (по умолчанию 20) на IP в сутки, очередь не больше 30.
2. Воркер `leads-diagnost` (`src/collectors/diagnost-worker.ts`, PM2) забирает аудит и проходит 11 этапов (`src/lib/diagnost/stages.ts`), записывая прогресс в БД. Зависшие больше 6 минут помечаются `failed`.
3. Конвейер (`src/lib/diagnost/run.ts`): HTTP главной → внутренние страницы (контакты, цены, услуги, отзывы…) → Playwright 1440×900 и 390×844 (скриншоты, метки первого экрана, LCP/FCP/CLS, вес и запросы) → robots/sitemap → детерминированные проверки → DeepSeek Flash по фактам и скриншотам → повторные проверки → скоринг → AI-сводка.
4. Страница `/diagnost/r/<slug>` опрашивает `GET /api/diagnost/<slug>` раз в 1,2 с: экран прогресса → дашборд.
5. PDF: `GET /api/diagnost/<slug>/pdf?kind=client|pro` — Playwright печатает `/diagnost/r/<slug>/print`.

## Оценка

- Проверка: «да» = 1, «частично» = 0,5, «нет» = 0. «Недостаточно данных» и «инфо» в балл не входят.
- Категория без данных (проверено меньше 40% веса) — «Недостаточно данных», в общий балл не входит.
- Веса: Конверсия 25, Оффер 20, UX 15, SEO 15, Скорость 10, Доверие 10, Аналитика/Реклама 5.
- Готовность к рекламе: конверсия 35, аналитика 25, оффер 15, UX 15, скорость 10 + потолки: ошибка сайта → 15, нет каналов связи → 35, нет HTTPS → 50, нет viewport → 55, нет Метрики → 60, нет CTA на компьютере и телефоне → 65.
- Вердикт: «можно запускать» при ≥ 75 и 0 критичных, «после исправлений» при ≥ 45, иначе «пока не рекомендуется».
- Приоритеты: влияние × уверенность ÷ сложность, топ-10.

## AI

- `DEEPSEEK_API_KEY` в `.env`, модель `DIAGNOST_MODEL` (по умолчанию `deepseek-flash`).
- Два вызова. Анализ скриншотов (тип бизнеса, оффер, первый экран) — с режимом рассуждений. Сводка и комментарий директолога — без рассуждений и с `temperature: 0` (в режиме рассуждений температура игнорируется).
- Модель получает только собранные факты (`visionFacts`, `summaryPayload`) и два скриншота. SEO-теги (description), слабые кнопки и дубли текста телефона не отправляются — это проверяется кодом. Риски и список «до запуска» строятся детерминированно, AI пишет только текст.
- Повтор: если сайт не менялся (отпечаток фактов без текста первого экрана — его меняют карусели), анализ берётся из аудита того же хоста за 30 дней; сводка — если совпали баллы и проблемы. Повтор неизменившегося сайта — 0 токенов.
- Расход каждого аудита пишется в `result.ai.usage` (токены, рассуждения, кэш, ≈ $ с учётом ночной скидки) и выводится в PDF директолога.
- Замер 19.10.2026: divan.ru 7 070 → 4 861 токен, стоматология 5 938 → 4 522; повтор divan.ru — 0.
- Цитата оффера принимается, только если встречается на странице. Оценки AI в проверках идут с уверенностью 0,7–0,75.
- Без ключа или при ошибке API аудит всё равно завершается: тип бизнеса — эвристикой, сводка — шаблоном.

## Развитие

- **SEO внутри Техосмотра (D.9).** Отдельная вкладка «SEO» в отчёте и PDF, проверка внутренних страниц: дубли title, пустые description, битые ссылки, структура заголовков. Причина: SEO уже есть в Техосмотре (15%), «Архитекторе» и Стратеге — четвёртый сервис про то же запутает. Карточку SEO AI с главной убрать.
- **SEO AI отдельно (D.10, на паузе).** Только мониторинг позиций и ключевых слов по подписке — другая задача, чем разовая проверка перед рекламой. Старт при трёх условиях: платный источник позиций, оплаченный Wordstat, первый платящий клиент. Выдачу Яндекса с хаба не собирать.

## Ограничения

- Скорость — лабораторный замер с нашего сервера, не данные реальных посетителей.
- Цели Метрики автоматически не проверяются — только наличие счётчика.
- История «Мои аудиты» привязана к куке браузера.
- Всплывающие окна (выбор города, cookies) остаются на скриншоте как есть.
