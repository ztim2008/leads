## Что нужно от партнёра

| # | Что | Пример |
|---|-----|--------|
| 1 | **Profi.ru аккаунт** | Логин + пароль от кабинета специалиста |

## 🔧 Подключение: 3 шага

### Шаг 1: Ты (админ) создаёшь источник
Зайди в админку → добавить источник для партнёра:
- Логин/пароль Profi
- Ключевые слова / минус-слова
- Бюджет (от/до)
- Telegram Chat ID + Token
- Запомни **Source ID** (UUID)

### Шаг 2: Партнёр покупает VPS и даёт IP
Партнёр:
1. Покупает VPS (см. таблицу выше)
2. Подключается по SSH
3. Сообщает тебе IP-адрес (или даёт доступ по SSH)

### Шаг 3: Запуск агента одной командой
На VPS партнёра:
```bash
curl -fsSL https://leads.konversus.ru/agent/setup.sh | bash -s "SOURCE_ID"
```

Где `SOURCE_ID` — ID источника из шага 1.

Всё! Через 2-3 минуты агент запущен и собирает заявки.

## 🛡 Как это работает (схема)

```
┌──────────────────────────┐        ┌──────────────────────┐
│   VPS ПАРТНЁРА (KZ)      │        │  ТВОЙ СЕРВЕР (KZ)    │
│                          │        │                      │
│  ┌────────────────────┐  │ POST   │  ┌────────────────┐  │
│  │ agent.mjs          │──┼───────►│  │ /api/agent/    │  │
│  │ ┌────────────────┐ │  │ leads  │  │    leads       │  │
│  │ │ Playwright     │ │  │        │  │    config      │  │
│  │ │ + Profi сессия │ │  │        │  │    heartbeat   │  │
│  │ └────────────────┘ │  │◄───────│  └────────────────┘  │
│  │                    │  │ config │                      │
│  │ 💓 heartbeat 5мин  │──┼───────►│  ┌────────────────┐  │
│  └────────────────────┘  │        │  │ PostgreSQL     │  │
│                          │        │  │ (общая БД)     │  │
│   IP: 185.x.x.x          │        │  └────────────────┘  │
│   Profi видит ЭТОТ IP    │        │                      │
└──────────────────────────┘        └──────────────────────┘
```

**Profi видит:** разные IP у каждого партнёра → не может связать аккаунты → не блокирует.

**Ты видишь:** все заявки в одной админке, все heartbeats, все статусы.

## 🔄 Что если VPS партнёра упал?

**Сейчас (v1):** ты получаешь алерт в Telegram, партнёр чинит VPS.

**Позже (v2 — fallback):** твой сервер автоматически подхватывает сбор заявок для этого партнёра (через прокси), пока его VPS не восстановится.

## 🌍 Где VPS: Россия или Казахстан?

| | Казахстан | Россия |
|---|:--:|:--:|
| Profi.ru | ✅ | ✅ |
| Telegram (через наш API) | ✅ | ✅ |
| Цена | ~2500 ₽/мес | ~800-1500 ₽/мес |
| Надёжность | Высокая | Достаточная |

**Почему РФ работает:** агент на VPS отправляет заявки на наш сервер в Казахстане. Telegram-уведомления шлёт наш сервер — не затрагивая РКН.

**Рекомендация:** если бюджет важен — Beget/Timeweb РФ. Если важна максимальная надёжность — PS.kz Казахстан.
