## 🎯 Концепция

Поиск заказов в публичных Telegram-каналах и группах **без подключения к ним**. Использует Telegram Global Search API (MTProto, не Bot API).

```
Telegram Global Search
        │
        ▼
┌───────────────────────────────────┐
│       🦅 Telegram Hunter          │
│                                   │
│  20-30 поисковых фраз            │
│  ├ «ищу мастера ремонт ...»      │
│  ├ «нужен плиточник ...»         │
│  ├ «кто делал ремонт ...»        │
│  └ «посоветуйте мастера ...»     │
│                                   │
│  Фильтры:                         │
│  ├ NLU: ищет заказ vs реклама    │
│  ├ Гео: Москва / Питер / любой   │
│  ├ Анти-шум: минус-слова         │
│  └ Дедупликация: не повторять    │
│                                   │
│  Доставка:                        │
│  ├ Telegram-уведомление          │
│  ├ Сохранение в БД как Lead      │
│  └ Рассылка партнёрам            │
└───────────────────────────────────┘
```

## 🧠 Логический стек

### Типы заявок (вес)

| Тип | Пример | Вес |
|-----|--------|-----|
| 🔥 Прямой запрос | «Ищу бригаду на ремонт двушки, срочно» | 10/10 |
| ⭐ Рекомендация | «Посоветуйте хорошего плиточника» | 9/10 |
| 💡 Вопрос-потребность | «Кто делал кухню под ключ? Сколько вышло?» | 7/10 |
| 📌 Общий запрос | «Где найти мастера по ремонту в Москве?» | 5/10 |
| 🗑 Шум (пропускаем) | «Я делаю ремонты, обращайтесь!» | 0/10 |

### Ключевые слова

```
ремонт:     ищу мастера, нужен ремонт, требуется отделочник,
            кто делал ремонт, посоветуйте плиточника,
            бригада на ремонт, ремонт под ключ

сантехника: течёт труба, нужен сантехник, замена стояков,
            унитаз установить, смеситель поменять

электрика:  нужен электрик, щиток собрать, проводка,
            розетки перенести, замена проводки

дизайн:     нужен дизайнер, проект интерьера, визуализация,
            дизайн-проект квартиры

клининг:    нужна уборка, клининг квартира, помыть окна,
            генеральная уборка
```

### NLU-фильтр: ищет или предлагает?

```
«Я делаю ремонты, опыт 5 лет»
  → intent: SELF_PROMOTION → ❌ ПРОПУСТИТЬ

«Ищу бригаду на ремонт двушки, срочно»
  → intent: LOOKING_FOR_MASTER → ✅ ЗАЯВКА

«Кто делал кухню под ключ? Сколько вышло?»
  → intent: ASKING_FOR_RECOMMENDATION → ✅ ЗАЯВКА
```

## 🔧 Технический стек

### Архитектура файлов

```
src/lib/hunters/
├── telegram/
│   ├── client.ts        # MTProto-клиент (gramjs)
│   ├── search.ts        # Поиск по фразам
│   ├── filter.ts        # NLU-фильтр
│   ├── dedup.ts         # Дедупликация
│   └── keywords.ts      # Ключевые слова
├── types.ts
└── index.ts

src/app/api/hunter/
├── telegram/route.ts    # API результатов
└── config/route.ts      # Настройка фраз
```

### Технологии

| Слой | Инструмент | Почему |
|------|-----------|--------|
| Telegram | `gramjs` (MTProto) | Работает с User API для поиска |
| Поиск | `messages.searchGlobal` | Родной метод Telegram |
| NLU | Правила + ключевые слова | 80% точности без ML |
| Гео | Regexp по городам | Москва, СПб, Казань... |
| Дедоп | externalId в БД | Не повторять найденные |
| Крон | Каждые 30-60 мин | Рейт-лимит ~30 запросов/мин |

### Поток данных

```
Крон (30 мин)
  → Для каждой фразы:
    → searchGlobal()
    → Фильтр: время (только новые)
    → NLU: ищет заказ vs шум
    → Гео: нужный город
    → Дедоп: проверка externalId
  → Сохранение в Lead
  → Telegram админу:
     🦅 3 новых заявки
     🔥 «Ищу бригаду...»
     📍 Канал: Объявления Москва
     🔗 t.me/obyavleniya_msk/4281
```
