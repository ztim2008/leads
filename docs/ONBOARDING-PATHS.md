Цены «999 ₽» и «партнёр сам обязан купить VPS + BotFather» **устарели**. Ниже — сжатая карта вариантов с актуальными правилами.

## Роли

| Роль | Кто | Что делает |
|------|-----|------------|
| **Админ** | Алексей | Сервер, БД, VPS-агент, Счета, Пульт |
| **Напарник** | Продажи | Реклама, Zoom, квалификация, чек-лист админу |
| **Партнёр** | Клиент | Оплата, Telegram, отклики, фильтры в кабинете |

## Путь E (основной) — «технику делает админ»

См. полностью: [PATH-E-ZERO-TOUCH.md](./PATH-E-ZERO-TOUCH.md).

```
Напарник: найти → Zoom → чек-лист
Админ:    партнёр в системе → VPS → agent v2 → проверка
Партнёр:  Telegram + кабинет + оплата
```

---

## Путь B — «уже есть Profi-специалист»

То же, что E, но не заводим новый кабинет Profi: партнёр отдаёт доступ админу (отдельный канал). VPS всё равно отдельный.

---

## Путь C — студия / несколько ниш

Один Profi = один VPS = один source. Несколько ниш — через фильтры (плюс/минус), не через второй агент на том же IP.  
Два аккаунта Profi → два VPS.

---

## Путь D — VIP (по согласованию)

Отдельные договорённости (белый лейбл, выделенный объём поддержки). Цена не «999 ₽» — только через админа. Технические запреты хаба те же.

---

## Путь A (архив формулировки)

Раньше описывал «партнёр сам покупает VPS и создаёт бота».  
Сейчас инфраструктуру по умолчанию закрывает админ (стоимость VPS в счёте 40 ₽/день). Если партнёр настаивает на своём VPS — админ принимает IP и всё равно сам ставит агент.
