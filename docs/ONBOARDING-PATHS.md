# 🔄 Пути подключения партнёров — роли и действия

## 👥 Роли

| Роль | Кто | Что делает |
|------|-----|------------|
| **Админ** | Алексей (ты) | Сервер, БД, API, техника, мониторинг |
| **Менеджер** | Твой друг | Приводит партнёров, общается, помогает с настройкой |
| **Партнёр** | Клиент | Покупает VPS, даёт доступ к Profi, платит подписку |

---

## 🅰️ Путь A: Новый партнёр «под ключ»

_Самый частый путь. Менеджер нашёл клиента, админ всё настроил._

```
Этап 1 — Менеджер
  ├── Находит партнёра (дизайнер, разработчик, студия)
  ├── Объясняет ценность: «Заявки с Profi сами приходят в Telegram»
  ├── Узнаёт:
  │   ├── Нишу партнёра (сайты? дизайн? seo?)
  │   ├── Бюджет заказов (от/до)
  │   └── Города (если важно)
  └── Передаёт Админу: контакты + нишу

Этап 2 — Партнёр
  ├── Регистрируется на Profi.ru как специалист
  ├── Покупает VPS в Казахстане (~2000 ₽/мес)
  │   └── PS.kz или Timeweb Cloud (зона KZ)
  ├── Создаёт Telegram-бота через @BotFather
  │   └── Получает: Bot Token + Chat ID
  └── Передаёт Админу:
      ├── Логин/пароль от Profi
      ├── IP и доступ к VPS (или даёт админу SSH)
      └── Bot Token + Chat ID

Этап 3 — Админ
  ├── Заходит в админку → «Источники» → «Добавить»
  ├── Вводит: логин/пароль Profi, ключевые слова, минус-слова
  ├── Указывает бюджет (от/до)
  ├── Вводит Telegram партнёра
  ├── Сохраняет → получает Source ID
  ├── Подключается по SSH к VPS партнёра
  └── Запускает: curl ... | bash -s "SOURCE_ID"

Этап 4 — Проверка
  ├── Админ: проверяет heartbeat в админке
  ├── Менеджер: просит партнёра подтвердить «заявки приходят?»
  └── Партнёр: получает первую заявку в Telegram 🎉
```

### ⏱ Тайминг пути A

| Кто | Действие | Время |
|-----|----------|-------|
| Менеджер | Разговор с клиентом | 30-60 мин |
| Партнёр | Покупка VPS + регистрация Profi | 30 мин |
| Админ | Создание source + запуск агента | 5 мин |
| **Итого** | | **~1 час** |

## 🅱️ Путь B: «У партнёра уже есть Profi»

_Партнёр уже работает на Profi, хочет автоматизацию._

```
Отличие от пути A — этап 2 короче:

Этап 1 — Менеджер
  └── То же самое: найти, объяснить, узнать нишу

Этап 2 — Партнёр
  ├── Покупает VPS (~2000 ₽/мес)
  ├── Создаёт Telegram-бота
  └── Передаёт Админу: логин/пароль Profi, доступ к VPS, Telegram

Этап 3 — Админ
  └── То же: создать source → запустить агента

⚠️ Важно: партнёр должен быть «специалистом» на Profi,
   не «заказчиком». Если он заказчик — нужна регистрация как специалист.
```

---

## 🅲️ Путь C: «Партнёр-студия» (много категорий)

_Студия или агентство работает в нескольких нишах. Нужны разные ключевые слова._

```
Отличие от пути A:

Этап 2 — Партнёр
  └── Передаёт несколько наборов ключевых слов:
      ├── «Сайты»: тильда, вордпресс, лендинг, создание сайта
      ├── «Дизайн»: логотип, фирменный стиль, брендинг
      └── «SEO»: продвижение, раскрутка, трафик

Этап 3 — Админ
  ├── Создаёт ОДИН source для студии
  ├── Ключевые слова: все ниши через запятую
  ├── Минус-слова: то что не нужно (игры, 1с, бухгалтер)
  └── Запускает ОДИН агент на VPS

💡 Один VPS = один IP = один Profi аккаунт = один source.
   Если студии нужно 2 разных Profi аккаунта → 2 VPS.
```

## 🅳️ Путь D: «VIP-партнёр» (полная изоляция)

_Крупный клиент, который хочет свой домен и полную автономию._

```
Отличие от пути A — партнёр получает больше:

Этап 2 — Партнёр
  ├── Покупает VPS помощнее (4-8 GB RAM)
  ├── Покупает домен (если хочет свой кабинет)
  └── То же: Profi + Telegram

Этап 3 — Админ
  ├── Создаёт source как обычно
  ├── Запускает агента как обычно
  ├── Дополнительно: настраивает отдельный Telegram-бот
  │   с кастомным именем и аватаркой
  └── По желанию: белая метка — кабинет на поддомене
      (partner.leads.konversus.ru)

💰 Цена: подписка Pro 999 ₽/мес + VPS ~3000 ₽/мес
```

## 📋 Шпаргалка для менеджера

### Что сказать партнёру при первом контакте

```
«Мы подключаем автоматический сбор заявок с Profi.ru.
Вы получаете заказы в Telegram с AI-анализом:
— рейтинг заказчика ⭐
— сколько лет на платформе
— вероятность что это реальный человек, а не бот
— готовый текст отклика

Стоимость: 999 ₽/мес + VPS ~2000 ₽/мес.
Первая неделя — бесплатный тест.»
```

### Что нужно собрать с партнёра (чек-лист)

```
☐ Ниша (какие услуги?)
☐ Ключевые слова (по каким заказам искать?)
☐ Минус-слова (что НЕ искать?)
☐ Бюджет заказов (от/до)
☐ Города (Москва, СПб, вся Россия?)
☐ Логин/пароль Profi.ru
☐ Telegram: Bot Token + Chat ID
☐ VPS: IP-адрес + доступ (root-пароль или SSH-ключ)
```

### Что партнёр делает сам

```
1. Profi.ru → зарегистрироваться как специалист
2. Купить VPS (ps.kz или timeweb.cloud, зона Казахстан)
3. Telegram → @BotFather → /newbot → получить токен
4. Telegram → @getmyid_bot → получить Chat ID
5. Передать все данные менеджеру
```

## 🔧 Шпаргалка для админа

### Добавить партнёра (2 минуты)

```bash
# 1. Создать source в админке или через БД
# Запомнить SOURCE_ID (UUID)

# 2. Подключиться к VPS партнёра
ssh root@IP_ПАРТНЁРА

# 3. Запустить установку
curl -fsSL https://leads.konversus.ru/agent/setup.sh | bash -s "SOURCE_ID"

# 4. Проверить
pm2 status
pm2 logs leads-agent --lines 10
```

### Проверить что агент жив

```bash
# На своём сервере:
curl -s 'http://localhost:3005/api/agent/heartbeat' \
  -X POST -H 'Content-Type: application/json' \
  -d '{"secret":"leads-agent-secret-2026","sourceId":"UUID"}'
```
