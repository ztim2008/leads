# CRM «Наши клиенты» + роль напарника (sales)

> v1 · 21.08.2026

## Роли

| Роль | Код | Доступ |
|------|-----|--------|
| Админ | `admin` | Всё + **Клиенты** + **Команда** |
| Напарник | `sales` | Только **/dashboard/crm** — **свои** карточки |
| Партнёр | `user` | Кабинет заявок (как раньше) |

**Изоляция:** напарник видит только клиентов с `ownerId = он`. Карточки админа ему **не видны** (404 на чужой id). Админ видит всех; фильтр «Только мои» — опционально.

## Где в UI

- Оператор → **Клиенты** (`/dashboard/crm`)
- Оператор → **Команда** (`/dashboard/admin/team`) — создать sales, пароль, вкл/выкл вход
- Вход напарника: `/auth` → редирект на `/dashboard/crm`

## Статусы

`lead` → `zoom` → `agreed` → `ready` → `connected` (+ `paused` / `rejected`)

Очередь админу: статус **К подключению** (`ready`). После install — **Привязать** workspace партнёра.

## Безопасность

- В CRM нет паролей Profi / VPS
- Связь с партнёром и удаление карточки — только админ
- Переназначение `ownerId` — только админ
- `loginEnabled=false` блокирует вход sales
