# 🔄 Логистика подключения партнёра

> **Роли:** Менеджер → Админ → Автоматика
> **Версия:** 1.0 · 29 июля 2026

---

## 📋 Общая схема

```
МЕНЕДЖЕР                    АДМИН                      АВТОМАТИКА
─────────                   ─────                      ──────────
Находит клиента
  │
Узнаёт нишу, бюджет
  │
Собирает данные             Принимает данные
(см. чек-лист ниже)    ───►  │
                             Заполняет форму
                             в админке (2 мин)
                                │
                             Нажимает                     Создаётся User
                             «Создать» ───────────────►  + Workspace
                                                          + Settings
                                                          + Source
                                                          ← Возвращает
                             Видит команду:                  setup-команду
                             curl ... | bash
                                │
                             Подключается по SSH
                             к VPS партнёра
                                │
                             Вставляет команду ─────────►  Агент устанавливается
                                                          Node + PM2 + Playwright
                                                          Запускается
                                │
                             Проверяет:                      ← Heartbeat (5 мин)
                             pm2 status                        Заявки в Telegram
                                │
                             «Готово!» ───► Менеджер ───► Партнёр получает
                                                             первую заявку 🎉
```

## 👤 Действия Менеджера

### Что узнать у партнёра

```
┌─────────────────────────────────────────────────────────┐
│               📋 ЧЕК-ЛИСТ МЕНЕДЖЕРА                      │
├─────────────────────────────────────────────────────────┤
│ ☐ Ниша партнёра (сайты? дизайн? seo? боты?)             │
│ ☐ Ключевые слова (что ищем)                              │
│ ☐ Минус-слова (что НЕ ищем)                              │
│ ☐ Бюджет заказов: от ______ до ______ ₽                 │
│ ☐ Города (Москва? СПб? Вся Россия?)                     │
│ ☐ Логин Profi.ru: ________________                      │
│ ☐ Пароль Profi.ru: ________________                      │
│ ☐ Telegram Chat ID: ________________                     │
│ ☐ Telegram Bot Token: ________________                   │
│ ☐ VPS IP: ________________                               │
│ ☐ VPS root-пароль: ________________                      │
├─────────────────────────────────────────────────────────┤
│ 📎 Передать админу любым способом (Telegram, голосом)    │
└─────────────────────────────────────────────────────────┘
```

### Что партнёр делает САМ (если путь не Zero-Touch)

Если партнёр готов участвовать — он делает:
1. **Profi.ru** → зарегистрироваться как специалист → заполнить анкету → получить логин (в поле «Логин» в настройках анкеты)
2. **VPS** → купить (ps.kz, 4 GB) → прислать IP и root-пароль
3. **Telegram** → @BotFather → /newbot → прислать токен → @getmyid_bot → прислать Chat ID

Если партнёр Zero-Touch (путь E) — всё это делает Админ.

## 🖥 Действия Админа

### Шаг 1: Получить данные от Менеджера

Менеджер передаёт заполненный чек-лист (см. выше).

### Шаг 2: Создать партнёра в админке

```
1. Зайти: https://leads.konversus.ru/dashboard/admin
2. Нажать: [+ Добавить партнёра]
3. Заполнить форму:
   ├── Email + пароль (для входа партнёра в кабинет)
   ├── Логин/пароль Profi
   ├── Ключевые слова / минус-слова
   ├── Бюджет от/до
   └── Telegram Chat ID + Token
4. Нажать: [✅ Создать партнёра]
5. Скопировать появившуюся команду (кнопка 📋)
```

### Шаг 3: Запустить агента на VPS

```bash
# Подключиться к VPS партнёра
ssh root@IP_ПАРТНЁРА

# Вставить скопированную команду:
curl -fsSL https://leads.konversus.ru/agent/setup.sh | bash -s "UUID-ИСТОЧНИКА"

# Проверить
pm2 status
# Должен быть: leads-agent online
```

### Шаг 4: Проверить работу

```bash
# На своём сервере — проверить heartbeat:
curl -s 'http://localhost:3005/api/admin/partner/setup?sourceId=UUID' | python3 -m json.tool

# Должен показать:
# "lastHeartbeat": "2026-07-29T..."
# "status": "ok"
```

### Шаг 5: Сообщить Менеджеру

```
«Готово! Партнёр [ИМЯ] подключен.
 Заявки пойдут в Telegram в ближайшие 10-15 минут.
 Кабинет: https://leads.konversus.ru/dashboard
 Логин: [email]
 Пароль: [password]»
```

## 📊 Статусы агента

| Статус | Значение |
|--------|----------|
| 🟢 `ok` | Агент жив, заявки собираются |
| 🟡 `pending` | Только что создан, агент ещё не запущен |
| 🔴 `error` | Ошибка (входа, сети, блокировка) |
| ⚫ нет heartbeat >15 мин | VPS упал или агент остановлен |

## 🛠 Команды админа (шпаргалка)

```bash
# Проверить всех партнёров
curl -s 'http://localhost:3005/api/admin/partners' | python3 -c "
import json,sys
d=json.load(sys.stdin)
for p in d['partners']:
    ws=p.get('workspace',{})
    srcs=ws.get('sources',[])
    for s in srcs:
        print(f'{p[\"email\"]:30s} {s[\"id\"][:8]}... {s[\"status\"]}')
"

# Получить команду для конкретного source
curl -s 'http://localhost:3005/api/admin/partner/setup?sourceId=UUID'

# Посмотреть логи агента на VPS
ssh root@IP_ПАРТНЁРА 'pm2 logs leads-agent --lines 20 --nostream'

# Перезапустить агента
ssh root@IP_ПАРТНЁРА 'pm2 restart leads-agent'
```

## 🔐 Безопасность

| Что | Как |
|-----|-----|
| Пароли Profi | Хранятся в БД в JSON-поле config |
| Доступ к API агента | AGENT_SECRET в .env |
| VPS партнёра | Отдельный сервер, изолирован |
| IP адреса | У каждого партнёра свой → Profi не блокирует |
