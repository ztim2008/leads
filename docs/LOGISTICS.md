# Логистика подключения партнёра

> **Роли:** Напарник (продажи) → Админ → Система  
> **Версия:** 2.0 · 21 августа 2026  
> Заменяет устаревшую схему с «999 ₽» и обязательным BotFather у партнёра.

Связанные документы: [CJM_PARTNER_SALES.md](./CJM_PARTNER_SALES.md) · [SALES_ZOOM_SCRIPT.md](./SALES_ZOOM_SCRIPT.md) · [PATH-E-ZERO-TOUCH.md](./PATH-E-ZERO-TOUCH.md) · [OPERATOR_AGENT.md](./OPERATOR_AGENT.md)

## Общая схема

```
НАПАРНИК                         АДМИН                         СИСТЕМА
────────                         ─────                         ───────
Реклама / поиск на Profi
  │
Первый контакт + квалификация
  │
Zoom 20–30 мин
  │
«Да» + договорённость по оплате
  │
Чек-лист данных  ─────────────►  Принимает пакет
                                 │
                                 Создаёт партнёра
                                 (админка / operator:onboard) ──► User + Workspace
                                                                  + Source + Счёт
                                 │
                                 VPS + install agent v2 ───────► Heartbeat, сбор
                                 │
                                 Пульт: HB / CB / заявки
                                 │
«Готово, смотрите TG» ◄────────  Карточка доступа
  │
Партнёр: первая заявка в Telegram 🎉
```

## Роли

| Роль | Зона | Не делает |
|------|------|-----------|
| **Напарник** | Воронка, Zoom, доверие, чек-лист админу | SSH, install агента, флажок оплаты в БД |
| **Админ** | VPS, онбординг, Пульт, Счета, техника | Холодную рекламу вместо напарника |
| **Партнёр** | Оплата, Telegram, отклики, фильтры в кабинете | Настройку сервера и «ускорение ленты» |

Модель продукта: **не публичный SaaS**. Подключение только через админа.

## Деньги (операторский счёт)

Цены правит админ в **Оператор → Счета** (шаблон + на партнёра). Ориентир по умолчанию:

| Статья | Когда | Сумма |
|--------|--------|------:|
| Подключение | Разово | 5 000 ₽ |
| Поддержка | Каждый месяц (с 1-го) | 2 000 ₽ |
| API ИИ | Каждый месяц | 1 700 ₽ |
| VPS | Каждый день работы | 40 ₽/день |

Флажок **оплачен / не оплачен** один у админа и партнёра (меню Счёт + полоска на обзоре).

## Действия напарника

### 1. До Zoom

- Квалификация: специалист Profi (или готов завести), есть ниша, готов сам откликаться.
- SMS/питы: [SALES_SMS_PITCHES.md](./SALES_SMS_PITCHES.md).
- Шпаргалка на одну страницу: [sales-cheat-sheet.html](./sales-cheat-sheet.html) (печать → PDF).

### 2. Zoom

Сценарий: [SALES_ZOOM_SCRIPT.md](./SALES_ZOOM_SCRIPT.md).  
Не просить пароль Profi в чат Zoom. Не обещать N заявок в день.

### 3. После «да» — пакет админу

```text
ПОДКЛЮЧЕНИЕ — после Zoom

Имя / как обращаться:
Telegram:
Ниша:
Город / регион:
Уже есть Profi специалист? да/нет
Плюс-темы:
Минус-темы:
Бюджет от–до:
Куда слать заявки (TG):
Оплата (договорённость):
Когда подключить:
Заметки:
```

Логин/пароль Profi и root VPS — **только админу**, отдельным каналом.

### 4. После подключения

- Написать партнёру: «смотрите Telegram, первая карточка скоро».
- Через 1–2 дня: «доходят заявки? фильтры ок?»
- Проблемы с HB/CB — сразу админу, не «чинить» самому.

## Действия админа

### 1. Пакет от напарника

Проверить полноту. Если не хватает — список дыр напарнику, не партнёру в десятом сообщении.

### 2. Создать партнёра

- Админка: **+ Подключить** / форма нового партнёра  
  **или** `npm run operator:onboard` ([OPERATOR_AGENT.md](./OPERATOR_AGENT.md), skill `leads-partner-onboard`).
- Email + пароль кабинета, Profi, лимит/месяц, Telegram, фильтры.
- Счёт: период, connectFee / periodPaid по факту оплаты.

### 3. VPS + агент v2

```bash
# На VPS партнёра (IP из онбординга)
curl -fsSL https://leads.konversus.ru/agent/v2/install.sh | bash -s "SOURCE_ID"
# точная команда — из карточки доступа / вывода operator:onboard
```

- Один партнёр = один VPS = один IP = один Profi.
- **Не** запускать Profi/Playwright на хабе (`profiOnHub: false`).
- Не рестартить `leads-agent-v2` без причины; при `login_failed` — CB, не спам входа.

### 4. Проверка

| Проверка | Ок если |
|----------|---------|
| Heartbeat | &lt; 15 мин |
| Circuit breaker | CLOSED |
| Пульт | не «зови агента» |
| Telegram | тестовая/первая заявка дошла |
| Счёт | суммы и флажок совпадают с договорённостью |

### 5. Сообщить напарнику и партнёру

```
Готово. Партнёр [ИМЯ] подключен.
Кабинет: https://leads.konversus.ru (email/пароль из карточки).
Заявки — в Telegram. Фильтры — в кабинете (без рестарта сервера).
```

## Статусы после запуска

| Сигнал | Значение | Действие |
|--------|----------|----------|
| HB свежий, CB CLOSED | Норма | Наблюдать |
| 0 заявок ночью 22–08 | Сон | Норма |
| 0 заявок днём при online | Фильтры / рынок | Смотреть фильтры, не ускорять ленту |
| CB OPEN / BLOCKED | Риск аккаунта | Стоп, админу; не сбрасывать CB вслепую |
| Нет HB &gt; 15 мин (рабочие часы) | VPS/агент | Админ по чеклисту; напарник не SSH |

## Безопасность

| Что | Как |
|-----|-----|
| Пароли Profi | Только админ / БД; не в git, не в рекламный чат |
| `.env` хаба | Никогда в коммит |
| IP | Разный на каждого партнёра |
| Deep scan / ускорение ленты | Запрещено как «помощь продажам» |
