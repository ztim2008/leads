# Managed Client Onboarding — План

## Концепция

Ты (админ) создаёшь аккаунт для клиента, настраиваешь источники, ключевые слова, Telegram — клиент получает готовую систему. Ему не нужно ни в чём разбираться.

## Как это работает сейчас

Клиент сам регистрируется на `/auth?tab=register` → получает пустой кабинет → должен сам подключить Profi → настроить фильтры → указать Telegram. Слишком сложно для обычного пользователя.

## Как должно работать

```
Админ (ты) → Админка → «Добавить клиента»
  ├── Email клиента (для входа)
  ├── Пароль (сгенерировать или задать)
  ├── Имя клиента
  ├── Profi.ru логин/пароль (клиент говорит тебе)
  ├── Ключевые слова (под нишу клиента)
  ├── Telegram Chat ID + Bot Token
  └── [Создать]

Система:
  1. Создаёт User + Workspace + Settings
  2. Подключает Profi как источник
  3. Настраивает фильтры/слова/бюджет
  4. Отправляет клиенту письмо:
     «Алексей подключил вам Konversus Leads AI.
      Ваш кабинет: https://leads.konversus.ru/dashboard
      Логин: client@email.ru
      Пароль: xxxxxx
      Система уже собирает заявки.»
  5. Worker начинает собирать заявки для этого клиента
```

## План внедрения

### Фаза 1: Форма добавления (1 час)
- Кнопка «+ Добавить клиента» в админке
- Форма: email, имя, пароль, источник, слова, Telegram
- Создание User + Workspace + Source + Settings одним запросом

### Фаза 2: Авто-письмо (30 мин)
- Отправка письма через nodemailer (как в Лид-радаре)
- Шаблон с логином/паролем

### Фаза 3: Управление клиентами (1 час)
- Включить/выключить клиента
- Редактировать настройки клиента
- Сбросить пароль
- Удалить клиента

## Ответы на вопросы

**Что если у клиента уже есть аккаунт?**
Проверяем email перед созданием. Если есть — предлагаем «привязать» к существующему.

**Кто платит за подписку?**
Пока ты управляешь тарифами вручную (через БД). Позже — ЮKassa.

**Видит ли клиент других клиентов?**
Нет. Middleware изолирует workspace-ы. Клиент видит только свои заявки.

**Что с Telegram-уведомлениями?**
Каждый клиент может указать свой Chat ID + Bot Token. Или использовать твоего бота с фильтром по чату.
