# SMS-питчи для рекламы / личных сообщений

> 5–7 коротких текстов. Один диалог = **1–2 SMS**, не вся пачка сразу.  
> Не писать: парсер, бот-ферма, «гарантия заказов», 999 ₽.  
> Цены — ориентир; точные цифры подтверждает админ.  
> Обновлено: 21.08.2026

---

## 1. Холодный первый контакт (Profi / реклама)

```
Здравствуйте! Помогаем специалистам на Profi не сидеть в ленте:
подходящие заказы приходят карточкой в Telegram — вы только откликаетесь.
Можем за 15–20 мин на Zoom показать, как это выглядит. Удобно?
```

---

## 2. Короче (лимит символов / объявление)

```
Заявки с Profi → в Telegram под ваши фильтры.
Без охоты за лентой. Zoom 20 мин — покажем. Написать «хочу»?
```

---

## 3. Акцент на скорость / конкурентов

```
Пока открываете ленту — у заказа уже пачка откликов.
Мы присылаем «ваши» заказы в Telegram раньше, чем вы успеете обновить страницу.
Рассказать на коротком созвоне?
```

---

## 4. Акцент на безопасность аккаунта

```
Не общий робот на всех: у каждого свой контур и свой сервер —
так аккаунты на Profi не «связывают».
Подключение делаем мы. Вам — Telegram и отклики.
Zoom?
```

---

## 5. После интереса «сколько стоит?»

```
Ориентир: подключение 5000 ₽ разово.
Дальше ежемесячно: поддержка 2000 + API ИИ 1700 + сервер ~40 ₽/день.
В кабинете один счёт: оплачен / не оплачен — без сюрпризов.
Детали — на Zoom или голосом.
```

---

## 6. Follow-up через 2–3 дня (мягкий)

```
Добрый день! Напоминаю про заявки с Profi в Telegram.
Если актуально — напишите удобное время на 20 мин, покажем на примере.
Если нет — ок, не беспокою.
```

---

## 7. После Zoom «подумаю» (один раз)

```
Как договорились — кратко:
• заказы с Profi → Telegram под фильтры
• отклик всегда ваш
• подключение и сервер — на нас
• цены: 5000 разово + месяц (поддержка/ИИ/сервер)
Когда скажете «подключаем» — передаю админу, обычно тот же/след. день.
```

---

## Что не слать в SMS

| Нельзя | Почему |
|--------|--------|
| Просьба сразу прислать пароль Profi | Страх, отвал |
| «999 ₽ / неделя бесплатно» | Устарело |
| «Гарантируем N заказов» | Не контролируем рынок |
| Длинные простыни про VPS/SSH | Не место |
