# Дорожная карта

## 🟢 Фаза 1 — MVP (готово)

- [x] Next.js 16 + TypeScript + Tailwind + Prisma + PostgreSQL
- [x] Плагинная архитектура коннекторов
- [x] Profi.ru через Playwright (логин + пароль + парсинг)
- [x] AI-анализ через DeepSeek Chat (оценка 0-100)
- [x] Определение робот/человек (botProbability)
- [x] Генерация 4 типов откликов
- [x] Telegram-уведомления
- [x] Автономный планировщик (каждые 5 мин)
- [x] Панель управления: обзор, заявки, источники, настройки
- [x] Дизайн-система: токены, Inter, Lucide, свет/тьма
- [x] SaaS multi-tenant архитектура
- [x] NextAuth авторизация
