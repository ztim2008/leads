# Яндекс Исполнители (бывш. Яндекс Услуги) — исследование · 31.10.2026

**Статус:** ⚪ не подключено. Решение — после проверки скорости писем у партнёра.

## Что выяснили

- Лента заказов исполнителя: `uslugi.yandex.ru/orders` → `GET /api/orders?completely_moderated=1&region=<id>&type=new&with_suggested_to_me=false` с заголовком `x-csrf-token` со страницы. Есть также `POST /api/get_my_orders_feed`.
- **Без входа лента всегда пустая** («Заказов в выбранных категориях пока нет»): заказы подбираются по категориям и районам из профиля исполнителя. Москва, `remote`, рубрика «Сайты под ключ» — `totalCount: 0`. Анонимная схема как у YouDo ([YOUDO.md](YOUDO.md)) не работает — нужен вход партнёра (Яндекс ID).
- Капчи на `/orders` при двух загрузках с хаба не было; регион определился по IP хаба (163 — Астана).
- Условия ([uslugi_termsofuse](https://yandex.ru/legal/uslugi_termsofuse/ru/), п. 3.2): запрещены программы и боты для **автоматических откликов**; оператор может заблокировать аккаунт «при выявлении подозрительной активности» (п. 4.5). Однотипные отклики → «подозрительная активность», блок откликов на 4–8 ч и до бана профиля.
- Экономика: дневной лимит откликов, безлимит 199 ₽/нед; 10% от суммы при закрытии заказа.
- Уведомления о новых заказах: почта, SMS, приложение; периодичность настраивается (Настройки → Письма и уведомления). Скорость писем не проверена.

## Риски входа под аккаунтом партнёра

- Яндекс ID — общий аккаунт партнёра (почта, Диск, платежи). Вход с IP датацентра → «подозрительный вход», подтверждение по SMS/push, возможна принудительная смена пароля.
- Сильная антибот-защита Яндекса (SmartCaptcha, отпечаток браузера).
- Нужны все правила Profi: постоянный профиль браузера, без повторных входов, circuit breaker, только чтение, без автооткликов.

## План

1. **Без риска:** партнёр включает письма о новых заказах в своих категориях (Сайты, удалённо) с наибольшей частотой и пересылает 2–3 письма. Если задержка ≤ 1–2 мин — разбор писем по IMAP на хабе, на Яндексе мы ничего не делаем.
2. Если письма медленные — агент с входом на VPS партнёра по схеме Profi, с письменного согласия партнёра на риск. Память: VPS пилота 2 ГБ, заняты ~1,2 ГБ двумя агентами; добавлена подкачка 2 ГБ, для третьего агента с браузером лучше 4 ГБ.
