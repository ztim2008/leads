## Что это

Админ ищет долгосрочную удалённую работу дизайнером карточек маркетплейсов. Радар смотрит HH, отсекает мусор правилами, ставит две оценки и пишет в Telegram, если вакансия свежая и откликов ещё мало.

Цепочка как у заявок, но **свои таблицы и свой процесс**:

```
HH (публичная выдача) → жёсткий фильтр → Match + Trust → лента
                                              ↓
                         мгновенная карточка  или  утренний разбор
```

Jabka **не подключена**. Отклик там платный. Не добавлять, пока человек сам не скажет.

## Профиль (один, в БД)

Таблица `job_radar_profile`, id `default`. Пока строка есть, `ensureRadarProfile()` её **не перезаписывает** дефолтом из кода.

| | |
|---|---|
| Специализация | Дизайнер карточек для маркетплейсов |
| Площадки | Wildberries, Ozon, Lamoda, Яндекс Маркет, Яндекс Кит, инфографика, карточки |
| Навыки | Figma, Photoshop, Midjourney, Runway, Kling, изображения, AI-видео, AI-аватары |
| Формат | удалёнка, долгосрочная работа |
| Минус | программирование, frontend, офис, продажи |
| Запросы HH | дизайнер карточек; дизайнер маркетплейсов; инфографика Wildberries; дизайнер Ozon |
| Зарплата | от 70 000 ₽, только с указанной зарплатой. Вилка проходит, если **верх** ≥ порога |
| Пороги пуша | совпадение ≥ 85, надёжность ≥ 70 |
| Лимит | 5 карточек в сутки |
| Тихие часы | 23:00–08:00 МСК |
| О себе | 7 лет карточек, 60–70 в неделю, цвет и характеристики, A/B. Текст в `about` |

Бренд в заголовке **не считается ролью**. «Менеджер Wildberries» отсекается. В заголовке должно быть слово из специализации, навыков или направления, которое не бренд.

UI: `/dashboard/radar/profile`. Сохранение — `PUT /api/radar/profile`. Пустые поля в форме настроек не затирают направления.

## Оценки

На карточке две цифры. Свежесть — это время, не третья оценка. Зарплата — факт, не оценка. Отдельного Fake Score нет.

**Совпадение** — правила: база 35, до 4 попаданий в профиль × 12, удалёнка +8, зарплата выше пола +8, полная занятость +5, потолок 100. Если правила ≥ 70 и есть `OPENROUTER_API_KEY`, DeepSeek (`deepseek/deepseek-chat`) может поправить балл. Не больше 6 таких вызовов за обход. В промпт уходит и `about`.

**Надёжность** — доля проверок: доверенная компания, компания указана, создана ≤ 72 ч, зарплата правдоподобна, описание ≥ 400 символов, не просят оплату, нет коротких ссылок. История работодателя считается только если число вакансий известно (сейчас обычно нет).

**Свежесть.** Горячая только если **оба** времени ≤ 45 минут: `creationTime` HH (не поднятие в поиске) и `firstSeenAt` сборщика. Старше 30 дней до страницы вакансии не ходим.

**Отклики.** Мгновенный пуш только если откликов ≤ 5 или HH число не отдал. Иначе вакансия остаётся в ленте и может попасть в утренний разбор.

## Telegram

Бот — тот, что в **Settings админа** (`leadskonversus_bot`), чат из этих же настроек (`778784292`).  
`TELEGRAM_BOT_TOKEN` в `.env` — это другой бот (`Leadweber_bot`). Им в этот чат писать нельзя: `chat not found`.

Кнопки карточки (callback, не ссылка):

| Кнопка | Что делает |
|--------|------------|
| Открыть | ссылка на HH |
| Отклик | следующее сообщение — черновик. На HH не отправляется |
| Скрыть | причины: не та роль / мало денег / уже смотрел |
| Откликнулся | статус `applied` |

`callback_data` до 64 байт, id вакансии — UUID. Разбор: `src/lib/radar/actions-parse.ts`. Слушает `getUpdates` процесс `leads-radar` (`src/lib/radar/inbox.ts`). Если у бота появится webhook, кнопки замолчат: в логе будет «у бота уже есть webhook». Второй поллер этого бота не поднимать.

Старое тестовое сообщение до 5 октября 2026 всё ещё со ссылкой «Скрыть» на `/api/radar/hide`. Новые карточки — только кнопки.

**Утренний разбор:** 08:00–08:20 МСК, одно сообщение, до 3 вакансий за ночь (с `quietStart` вчера). Возраст честный. Горячие с малым числом откликов в разбор не кладутся — они уходят отдельными карточками после 08:00. Пустой разбор `lastDigestAt` не ставит, следующий обход внутри окна ещё может отправить.

Тихие часы режут только мгновенные карточки. Сбор ночью идёт.

## Лента

Только админ, не во время имперсонации. Своё меню: Лента / Профиль / Настройки. В сайдбаре пункт «Job Radar».

| Вкладка | Статусы |
|---------|---------|
| В ленте | не `hidden` и не `applied` |
| Откликнулся | `applied` |
| Скрытые | `hidden` + причина |

Открытие карточки переводит `new` → `opened`. «Вернуть» ставит снова `new`.

Ручной обход: Настройки → «Собрать сейчас» → `POST /api/radar/run`.
